    2. Casos de teste para 100% de cobertura de branch:

Teste 1 - Preço Inválido
Entrada: price = 0.0, customerType = "VIP", quantity = 5

Saída Esperada: IllegalArgumentException com mensagem "Preço deve ser positivo"

Cobertura: Branch price <= 0 → true
-------------------------------------------------------------------------------------
Teste 2 - Cliente VIP com Quantidade Baixa
Entrada: price = 100.0, customerType = "VIP", quantity = 5

Saída Esperada: 100.0 × 0.15 = 15.0

Cobertura:

price <= 0 → false

customerType.equals("VIP") → true

quantity >= 10 → false
